# Student Management System

A CLI-based Student Management System built with Python using Object-Oriented Programming concepts.

## Versions

### Version 1 - OOP Based (`student_mng_oops_v1.py`)
Basic student management using OOP concepts.

### Version 2 - File & Exception Handling (`student_mng_oops_v2.py`)
Enhanced version with file handling and exception handling.
- Data is saved permanently in `students.txt`
- Handles invalid inputs gracefully

## Features
- Add Student
- Search Student by Roll Number
- View All Students
- Update Student Details
- Delete Student Record

## Concepts Used
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling
- Lists, Loops, Functions
- Enumerate

## How to Run
1. Clone the repository
   git clone https://github.com/ayushiwalia001-max/your-repo-name.git

2. Run Version 1
   python student_mng_oops_v1.py

3. Run Version 2
   python student_mng_oops_v2.py
